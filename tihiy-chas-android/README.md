# Тихий час (Android)
Защита фокуса: во время сессии несрочные уведомления убираются и приходят пачкой после неё.
Срочные (слова «срочно», «авария», «мама», «прод упал»), звонки, будильники и навигация проходят сразу.

Сборка: Android Studio (Open → эта папка) или GitHub Actions → артефакт `tihiy-chas-debug-apk`.
После установки включите доступ к уведомлениям (кнопка в приложении).
