# Кадр

Фото-соцсеть: посты, рилсы, лайки, комментарии, подписки, синяя галочка, поддержка через чат и админ-панель.
Сервер — один файл `server.js` без npm-зависимостей (Node 18+). Данные — `data/data.json`, медиа — `data/uploads/`.

## Официальный аккаунт @kadr
- Создаётся при первом запуске: имя `kadr`, роль админа, галочка, приветственный пост.
- Все новые пользователи автоматически подписаны на @kadr.
- Пароль генерируется случайно и записывается в `data/ADMIN_PASSWORD.txt` (на сервере — `/opt/kadr/data/ADMIN_PASSWORD.txt`).
  После первой смены пароля (Профиль → шестерёнка) файл удаляется.
- Только админы могут публиковать текстовые посты (объявления канала).

## Своя почта @домен
- `mail.js` принимает письма на любой адрес `@домен` (порт 25) и показывает их в админ-панели → «Почта». Отвечать и писать можно оттуда.
- Письма с кодами уходят с `noreply@домен`, подписаны DKIM. Ключ создаётся сам в `data/dkim.pem`.
- Нужные DNS-записи (A, MX, SPF, DKIM, DMARC) показаны в админ-панели → «Почта» → «Настройка» с отметками ✓.
- Если хостинг закрыл исходящий порт 25, отправку можно пустить через внешний SMTP: `set-mail.sh`.

## Бэкап
- Каждую ночь в 4:30 (служба `kadr-backup`): база `data-*.json.gz` и настройки `config-*.tar.gz` — 30 дней; фото и видео `uploads-*.tar` — по воскресеньям, 2 последние копии. Папка `/opt/kadr/backups`.
- Если подключён Telegram-бот, свежий архив базы приходит админам файлом.
- Вручную: `bash /opt/kadr/backup.sh --full`. Восстановить: `bash /opt/kadr/restore.sh` (покажет список) и `bash /opt/kadr/restore.sh <файл>`.

## Почта и Telegram
- Почта обязательна при регистрации и подтверждается 6-значным кодом из письма. По подтверждённой почте восстанавливается пароль.
- Подключить отправку писем: `bash /root/Emerald-brawl-kadr/deploy/set-mail.sh` (нужен пароль приложения почтового ящика).
- Подключить Telegram-бота: `bash /root/Emerald-brawl-kadr/deploy/set-telegram-token.sh`.

## Админ-панель
Профиль → «Админ-панель» (видна только админам):
- **Обращения** — тикеты поддержки: ответить, ответить и закрыть, закрыть, выдать или отклонить галочку по заявке.
- **Пользователи** — поиск, выдать или снять галочку, сделать админом, заблокировать, сбросить пароль (показывает временный).
- **Статистика**.

## Выкладка на VDS (с компьютера, где настроен SSH-ключ)
```
scp -r server.js public deploy root@193.247.73.123:/root/kadr/
ssh root@193.247.73.123 "bash /root/kadr/deploy/install.sh"
```
Скрипт ставит службу `kadr` (порт 3200, только localhost), сайт nginx для `kadr.193-247-73-123.sslip.io`
и сертификат certbot. S-Message не затрагивается. Повторный запуск = обновление, с копией data.json в `/opt/kadr/backups`.
В конце скрипт печатает логин и пароль @kadr.

Бэкап: добавить `/opt/kadr/data` в ежедневный бэкап сервера.

## Локальный запуск
```
PORT=3200 node server.js
```
